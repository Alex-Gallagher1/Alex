This Branch contains all of the code used to perform the fit for the Sersic indexes of several Galaxies to model the brightness profile of galaxies accurately. 

To properly run this code, there are several packages that will need to be installed. These are:
  Numpy
  Matplotlib.pyplot
  Scipy.Optimize
  Pandas

On top of those packages, the data itself was downloaded from this (https://cdsarc.cds.unistra.fr/viz-bin/cat/J/ApJS/234/18) dataset. 

Once all data and packages are downloaded and placed in the folder, simply open the notebook and run every cell to get the desired outcome.
